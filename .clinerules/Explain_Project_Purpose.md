# Explain Project Purpose

**Description:** Provide a high-level overview of the interactive mind map application.

**Context:**
- This is a web-based mind mapping tool built with React and D3.js.
- It focuses on unique layouts like parent-path highlighting and vertical leaf node alignment.
- The UI is decoupled from data sources and can render maps from text or JSON data.
